# PROJECT REQUIREMENTS

## Portfolio Purpose

This portfolio is a UX/UI Designer portfolio designed to showcase:

- UX thinking
- Research process
- Problem solving
- Design decisions
- Final digital experiences

The portfolio should not only display finished designs.

It should communicate the journey from:

Research → Exploration → Design → Digital Experience

The website concept is:

**Inside the Designer's Workspace: From Paper to Digital**

---

# Core Design Rules

Every page must feel like part of the same product.

The website must maintain consistency in:

- Colour system
- Typography
- Spacing
- Components
- Animation style
- Interaction patterns
- Visual language

Do not create pages that feel separate.

---

# Design Philosophy

The website should combine:

Human creativity + Digital precision

The experience should feel:

- Calm
- Creative
- Professional
- Thoughtful
- Human-centred

---

# Home Page

## Purpose

Introduce the designer and communicate the portfolio concept immediately.

The user should understand:

"I am entering a UX designer's creative workspace."

---

## Hero Concept

Theme:

## Beginning of the Design Process

The hero represents the transition from paper ideas to digital experiences.

Main visual:

A centred laptop showing a wireframe-style interface.

The laptop represents:

- Digital outcome
- Product design
- Interface creation

Supporting elements may include:

- Research notes
- Sketches
- Wireframe details
- Design annotations

The visual should feel like:

A designer's workspace evolving into a digital product.

---

## Hero Requirements

Include:

- Designer introduction
- Clear UX/UI positioning
- Main call-to-action
- Project exploration CTA

The hero must have:

- Strong hierarchy
- Clear readability
- Minimal clutter

# Signature Features

## Custom Cursor

Desktop only.

Concept:

Research magnifying glass cursor.

Meaning:

Curiosity and exploration.

Behaviour:

Default:
- Normal cursor

Research/project areas:
- Magnifying glass interaction

Clickable elements:
- Pointer cursor

Must not:

- Reduce accessibility
- Block interactions
- Affect performance

---

# Animation Requirements

Animations must have purpose.

Use animations for:

- Revealing information
- Showing relationships
- Providing feedback
- Improving navigation

Preferred:

- Fade transitions
- Smooth movement
- Gentle scaling
- Scroll reveals

Avoid:

- Excessive animations
- Long transitions
- Distracting movement

---

# Accessibility Requirements

The website must include:

- WCAG-friendly colour contrast
- Keyboard navigation
- Visible focus states
- Reduced motion support
- Responsive layouts
- Semantic HTML

---

# Responsive Requirements

The website must work consistently on:

- Desktop
- Tablet
- Mobile

Mobile should not feel like a separate website.

Maintain:

- Brand identity
- Hierarchy
- Usability
- Interaction quality

---

# Performance Requirements

Prioritise:

- Fast loading
- Optimised images
- Clean components
- Efficient animations

Avoid:

- Heavy effects
- Unnecessary libraries
- Large assets

---

# Implementation Rule

Do not redesign randomly.

Before implementing any change ask:

1. Does this support the Paper → Digital concept?
2. Does this improve UX?
3. Does this communicate my design process?
4. Does this maintain consistency?

If not, do not add it.
