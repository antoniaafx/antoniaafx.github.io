# DESIGN SYSTEM

## Design Philosophy

The design system should create a clean, modern, premium UX portfolio.

Consistency is more important than decoration.

Every component should feel intentional.

---

# Colour System

The colour palette should remain minimal.

Use one primary accent colour consistently throughout the website.

Accent colours should be reserved for:

- Buttons
- Links
- Active navigation
- Small highlights
- Interactive elements

Large areas of colour should be avoided.

The portfolio should rely primarily on whitespace and typography.

---

# Typography

Typography is one of the strongest elements of the portfolio.

Use typography to create hierarchy rather than relying on colour.

Headings should feel confident and elegant.

Body text should remain highly readable.

Text should never feel crowded.

---

# Spacing

Whitespace is part of the design.

Spacing should feel intentional and consistent.

Avoid:

- Large empty gaps
- Crowded layouts
- Uneven spacing
- Random padding values

Use one consistent spacing scale throughout the project.

---

# Components

Every component should follow the same visual language.

Cards, buttons, forms, navigation, and sections should feel like they belong to one design system.

Do not create unique styles for individual pages unless required by the overall concept.

---

# Cards

Cards should feel clean and lightweight.

Hover effects should be subtle.

Cards should never jump dramatically or distract from the content.

---

# Buttons

Buttons should communicate hierarchy.

Primary buttons should clearly stand out.

Secondary buttons should remain visually supportive.

Hover interactions should feel smooth and responsive.

---

# Icons

Icons should be simple and consistent.

Use one icon style throughout the website.

Avoid mixing outline and filled icons without purpose.

---

# Decorative Elements

Decorative elements should support the UX process theme.

Examples include:

- Wireframe grids
- Sticky notes
- Research annotations
- User journey connectors
- Design labels
- Blueprint lines

These elements should always remain subtle and should never overpower the content.

---

# Motion

Animations should be smooth, short, and purposeful.

Preferred animation style:

- Fade
- Small movement
- Scale
- Opacity
- Gentle transitions

Avoid:

- Bounce
- Large rotations
- Excessive parallax
- Long animation sequences

---

# Cursor

The cursor should reinforce the research theme.

It should remain intuitive.

Custom interactions should only appear when they improve the experience.

Accessibility should always take priority.

---

# Accessibility

Every page should:

- Meet WCAG best practices.
- Maintain strong colour contrast.
- Support keyboard navigation.
- Include visible focus states.
- Respect reduced motion preferences.
- Remain readable across all devices.

---

# Responsive Design

Desktop, tablet, and mobile should feel like the same product.

Layouts should adapt naturally without changing the overall design language.

No page should feel like a completely different experience on another device.
